## 🕹️ OverTheWire Bandit

OverTheWire is a free cybersecurity wargame platform that provides hands-on, terminal-based challenges designed to help users learn and practice practical security concepts and Linux command-line skills.

---

### 🖥️ Linux System & File Mastery
* Managing files with hidden attributes, complex spaces, or special characters (`-`).
* Using `find` with size and type filters while suppressing permission errors (`2>/dev/null`).
* Modifying file access rules with `chmod` and utilizing private SSH keys for target authentication.

### 📊 Data Processing & Analysis
* Filtering files via `grep`, `strings`, `sort`, and isolating unique lines with `uniq -u`.
* Reversing ciphers like ROT13 using `tr`, and decoding Base64 encoded text streams.
* Programmatically identifying file signatures and unpacking nested `gzip`, `bzip2`, and `tar` archives.

### 🌐 Network Operations
* Connecting to internal sockets and submitting data using the Netcat (`nc`) utility.
